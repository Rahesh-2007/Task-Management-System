# Reference Breakpoint Specifications

## 1. Desktop (1440px)
* **Navbar**: Full horizontal nav with logo, Features, For Teams, Resources, Pricing, Log in, and red "Start for free" button.
* **Hero**: Two-column layout with left copy (H1: "Your trusted second brain", subtext, CTA) and right / center interactive Task Manager Mockup.
* **Feature Grid**: 2-column or 3-column interactive cards with tinted red icon containers and preview graphics.
* **Social Proof**: 3-column publication quote cards ("The Verge", "PCMag", "TechRadar") + stats marquee.
* **Testimonials**: 3-column tweet-style quote cards with avatars, handles, timestamps, and verified checkmarks.
* **Footer**: 5 multi-column links + bottom copyright & language selector.

## 2. Tablet (820px)
* **Navbar**: Compact navbar with hamburger drawer trigger for screen widths < 960px.
* **Hero**: Stacked layout with central text lock-up and full-width interactive Task Manager Mockup.
* **Feature Grid**: 2-column stacked feature cards.
* **Social Proof & Testimonials**: 2-column grid or horizontal scroller.
* **Footer**: 2-3 column responsive grid.

## 3. Mobile (390px)
* **Navbar**: 60px height sticky bar with SVG logo and hamburger button. Opens full-screen sliding sheet.
* **Hero**: Single column stack with 36px H1, compact buttons, and mobile-optimized interactive task widget with swipe / tap interactions.
* **Feature Grid**: 1-column cards with responsive padding (16px).
* **Social Proof**: 1-column publication quotes & continuous marquee ticker.
* **Testimonials**: Single column testimonial stream.
* **Footer**: Accordion-style collapsible multi-column links.
